# 选题胶囊行为测试记录

## v2.1.0 Fresh 复测

- 日期：2026-08-17。
- 方式：三个请求分别使用互不复用的虚构档案或同一跨胶囊验收底座；测试 agent 未读取 behavior cases/results、评分标准、PR 文档或其他 agent 输出。
- 错误受众热点：咖啡店经营创作者没有追演唱会娱乐事件，而是改成活动日经营顺序；同时给出 Audience Job、主 IP Job，以及“评论只谈明星、没有店主问题就停止”的退出信号。
- 支柱外探索：40 份咨询中有 27 份出现照护者执行不一致时，允许做三条代际沟通探索题，但不立即改支柱；用目标用户试用反馈决定继续，讨论滑向婆媳对立或三条无反馈则停止。
- 跨胶囊选题：只交付一个“项目可能延期时用四句话让领导能做决定”的题，明确目标处境、需求/方案半句、主赌注、Audience Job、主 IP Job 和验证边界，没有输出完整脚本。
- 实际判定：三次均通过。既能纠正与目标受众冲突的热点，也允许有新证据的相邻探索，并持续继承关系、信任、记忆和业务方向。
- 覆盖边界：本轮覆盖错误热点、最小纠偏和支柱外探索；没有重新测试宽泛“女性成长”提示。

以上是 fresh-agent 行为证据；共享输入逐字一致、单胶囊结构和摘要过滤由 129 项 unittest 中的确定性测试另行验证。

## 2026-08-13 历史基线

- 一个 fresh agent 直接交付五个可执行选题，同时给出目标人群、主赌注和验证方式；没有只换标题、编造热度或为流量引入错误人群。
