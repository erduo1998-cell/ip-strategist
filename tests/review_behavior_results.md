# 复盘胶囊行为测试记录

## v2.1.0 Fresh 复测

- 日期：2026-08-17。
- 方式：最终验收使用一个全新的独立室内设计师虚构档案，工作目录故意包含连续两个空格；测试 agent 未读取 behavior cases/results、评分标准、PR 文档或其他 agent 输出。
- 路由结果：正确执行 `confirmed → review`，只点名并打开一份契约；`contract_to_open` 完整保留连续空格，摘要没有模板占位符或 Markdown 残留。
- 数据结果：摘要提供近期内容、主页访问/关注、合格申请/业务线索、搜索、系列相邻集和新粉留存；无需向用户补问即可完成判断。
- 实际判定：播放约为基线 22.6 倍、点赞率从 3.33% 升至 5.48%，但主页访问率、关注率、每万播放合格申请、搜索、相邻系列承接和 7 日留存均未改善，因此结论为“局部传播成功，内容项目承接失败，长期 IP 积累失败”。
- 证据纪律：评论支持“吸来业主和泛装修围观者”，但只有一个样本，仍标为待验证；下一批只改首屏人群限定，其余保持不变。
- 修复过程：更早的两个 fresh 场景先后暴露“复盘摘要缺数据表”和“缺主页/线索信号”，都只记为发现或部分通过；只有上述最终全新场景记为当前版本通过。
- 覆盖边界：本轮直接覆盖“高播放但低 IP 积累”；没有测试“播放一般但首次出现合格线索”，因此不把后者记为 v2.1 Fresh 通过。

以上是 fresh-agent 行为证据；路径无损、预算不足显式失败、数据行过滤和只读性由 129 项 unittest 中的确定性测试另行验证。

## 2026-08-13 历史基线

- 一个 fresh agent 在“复盘 + 变现”双交付请求中依据咨询率选出母版，区分证据与未知，下一批只验证一个变量；没有用总播放直接归因或改旧契约迁就结果。
