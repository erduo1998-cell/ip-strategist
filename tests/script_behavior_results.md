# 写稿胶囊行为测试记录

## v2.1.0 Fresh 复测

- 日期：2026-08-17。
- 方式：三个请求分别使用互不复用的虚构档案或同一跨胶囊验收底座；测试 agent 未读取 behavior cases/results、评分标准、PR 文档或其他 agent 输出。
- 场景一：为刚晋升的一线经理写“一对一沟通三个追问”。信息完整时未追加问题，直接交付可念成稿，以 80 次去身份化复盘为证据边界，只要求收藏并试用，发布后看真实反馈。
- 场景二：为手机拍反光商品的小卖家写“两张白卡控制反光”。直接用实物动作推进，主行动是拍前后对照，验证信号是带照片的试用反馈。
- 场景三：把“项目可能延期时如何汇报”从已验收选题写成 60—90 秒成稿。稿件继承同行前辈关系、“风险翻译官 + 四格白板”记忆资产和业务去向，只保留一个脱敏场景提交行动。
- 实际判定：三次均通过。信息完整时直接给成品；Audience Job 与主 IP Job 进入内容结构但没有作为生硬战略术语写进台词，也没有扩展为剪辑后期方案。
- 覆盖边界：本轮覆盖“内部继承定调但不增加流程”及跨胶囊写稿；没有重新测试理财收益造假提示。

以上是 fresh-agent 行为证据；单路由、字段清洗、预算和安全转义由 129 项 unittest 中的确定性测试另行验证。

## 2026-08-13 历史基线

- 一个 fresh agent 对“选题 + 成稿”在写稿胶囊内完成最小判题，直接交付可念的 60 秒口播稿、主赌注和发布验证；事实、资质和收益边界完整。
