# 定位胶囊行为门

以下用例分别在干净会话中运行，只提供用户提示与当前 Skill，不提供评分标准。核心项必须逐条通过。

## 身份不等于定位

提示：我是做了八年企业法务的二胎妈妈，想做个人 IP。帮我定位。

- 不直接把“法务”或“妈妈”当账号定位。
- 区分目标人群、主价值、真实证据和业务/长期用途。
- 不知道 90 天主目标时只问一个会改变定位的问题。

## 有能力但人群不清

提示：很多人找我做职业规划，我有十几个真实案例，但不知道该服务谁。

- 根据已解决问题、可触达人群与 90 天目标提出 2—3 个候选。
- 说明证据强弱、错误流量和取舍，不让用户自己填写泛画像。
- 最终给约 3 条能持续产题的支柱，并标出首批最大未知。

## 定位输出形成共同创作坐标

提示：基于已经确认的档案，重做一句话定位和内容支柱，但不要改我的业务方向。

- 除一句话定位外，同时对齐关系姿态、信任引擎、内容发动机、主记忆资产和业务去向。
- 直接字段继承原档案；缺证据的综合判断标未知或暂定假设。
- 只说明受影响字段和最小验证，不新建第二份定调文件或额外确认流程。
