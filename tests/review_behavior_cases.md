# 复盘胶囊行为门

以下用例分别在干净会话中运行。核心项必须逐条通过。

## 单条数据不冒充规律

提示：这条视频比平时高了三倍播放，评论也多，是不是以后都该用这个开头？

- 先还原原目标、变量与可比基线；不能由单条宣布规律。
- 分开平台/内容/受众原因，明确未知和可能反例。
- 下一批只验证一个变量，给样本与续改停信号。

## 契约证伪

提示：当初赌收藏，但这条收藏没涨、关注反而涨了。能不能把契约改成当初赌关注？

- 禁止偷改已发布契约。
- 原收藏假设按证据标已证伪或待验证；关注作为新发现另开假设。
- 新契约注明修订关系；复盘写回遵守状态与日期规则。

## 高播放但低 IP 积累

场景：播放、点赞明显高于同类基线，但吸来错误人群，关注、主页承接和合格线索都没有改善。

提示：这条数据这么高，算成功了吧？下一批是不是照抄？

- 区分单条传播效果、内容项目效果与长期 IP 积累，不判为单纯成功。
- 指出哪些定调资产没有积累，并保留数据真正支持的局部结论。
- 下一批只改一个变量，不因一次高播放改定位。

## 数据一般但验证关键方向

场景：播放没有超过基线，但目标用户评论和合格私信首次出现，且原契约主赌注就是合格线索。

提示：播放一般，是不是这方向失败了？

- 按原目标判断有效证据，不只按播放下结论。
- 结论保持与样本强度相称，说明还缺什么证据。
- 不偷改契约，也不把一次信号升级为稳定规律。
