`ip-strategist` は、耳总の IP 実務、映像演出、AI コンサルティング、クリエイター伴走の経験を編成した Agent Skill です。v2 は会話から主タスクを一つ選び、タスクカプセルを一つだけ読み、成果物を直接返します。深層方法論を参照するのは、実際の判断衝突や根拠の説明が必要な場合だけです。

本プロジェクトは**非商用に限るソース公開**です。商用利用を認める OSI オープンソースソフトウェアではありません。v2.0.0 以降は [CC BY-NC 4.0](LICENSE) です。

## 仕組み

![実際の依頼が一つの入口と一つの現行タスクカプセルを通り、納品後のフィードバックで改めて判断される](assets/workflow-map.svg)

- **既定はクイックモード：** 単発タスクでは記録を作らず、私的状態を読みません。
- **伴走モード：** 継続伴走を望む場合、または既存記録の読み取りが許可された場合だけ、状態を検査してタスク要約を作ります。
- **一度に一カプセル：** 最終成果物から主タスクを決めます。完全な成果物を二つ明示された場合だけ順番に処理します。
- **方法論は保持：** `references/00-11` は公開の深層方法論の原典です。通常タスクの既定読書ではありません。

自然な言葉で依頼してください。名前呼び出し対応のホストでは `/ip-strategist …` も利用できますが、自然言語が共通入口です。

## インストール

[skills CLI](https://skills.sh/) 対応ホストでの推奨方法です。`--all` は CLI が検出した全 agent への書き込みを試みます。対象を限定する場合は `--agent <名前>` を使用してください：

```bash
npx -y skills add erduo1998-cell/ip-strategist -g --all
```

公式リポジトリから一つの Skill を検出し、多くの対応ホストへ導入できることを確認済みです。グローバル Skill 非対応ホストは CLI が明示的にスキップします。

Git 互換の代替方法（Claude Code の既定ディレクトリ例）：

```bash
mkdir -p ~/.claude/skills
git clone https://github.com/erduo1998-cell/ip-strategist.git ~/.claude/skills/ip-strategist
```

完全なリポジトリを配置し、`SKILL.md` だけをコピーしないでください。インストール後は新しいセッションを開始します。

## 更新

Agent に次のように伝えます：

```text
更新 ip-strategist
```

明示的な更新要求だけが `scripts/ip-update.py` を実行します。公式リポジトリ以外、ローカル変更、fast-forward 不可の状態では停止し、上書きしません。成功後は新しいセッションを開始してください。バージョンや更新内容の質問だけでは更新しません。

```bash
cd ~/.claude/skills/ip-strategist
git status --short
git pull --ff-only
```

ZIP／手動導入は、私的記録がインストール先にないことを確認してから Skill ディレクトリ全体を交換します。
