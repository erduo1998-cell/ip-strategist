# 判断契约 · 对赌记录

> **使用说明：** 发布前复制本模板，填好一、二、三、四段并签订。发布那一刻起，这四段即冻结，不许回头改。复盘时改头部「状态」「下次复盘日」两个字段、并在第五段追加验证记录。这不是一张勾选表，是一份带推理的对赌记录——每条判断都得写清楚「为什么这么赌」，填不出来就是没想透，别发。
>
> **何时用完整契约 / 何时用轻量批次契约：** 同方向连续 3-5 条内容（同骨架 / 同人群 / 同钩子）可共签一份批次契约，共用控制变量与验证窗口，不必每条都填完整模板——日更创作者每条都签太重，批次契约把同批次的样本聚合到一份对赌记录里复盘即可；跨方向 / 试探新人群新骨架时仍各签各的。

## 一、我赌什么

这一段不过关，后面全是空中楼阁。选题不是话题，是需求 × 方案的双向奔赴——缺任何一半都不叫选题。

**1. 戳中的需求**：[具体描述。不是「变美」「赚钱」这种话题，是「谁在什么处境下、疼在哪、想要什么」。]
> 填写指引：写不出具体处境，就是没找到需求，回去重想。反例：「目标用户想提升审美」——这是话题不是需求。正例：「刚工作两年的女生，买衣服花钱不少但永远觉得自己穿得土，疼在「花了几千块还是没气质」。」

**2. 目标人群**：[谁。越具体越好，圈出人群标签。]
> 填写指引：「所有人」等于没人。至少有一个具体标签（年龄/处境/身份/场景）。

**3. 解决方案类型**（五选一，接 02 §2.4，每种赌注不同）：
- [ ] **资讯型**——赌信息差。你掌握、观众没掌握的差距越大含金量越高。
- [ ] **观点型**——赌反常识、纠正认识。老生常谈不算观点，最难做。
- [ ] **步骤技巧型**——赌真能解决问题、可落地、且新鲜。
- [ ] **生活方式 / 故事型**——赌让人羡慕、渴望，或给人指导。三至少沾一。
- [ ] **新体验型**——用新演绎讲一句正确的废话，赌你的状态、投入度能不能打动人。

**4. 这条的核心赌注**：[一句话，赌注失效这条视频就废。]
> 填写指引：早上刷牙洗脸送娃的流水账 vlog——既不让人羡慕、也不给人指导，没有兜底赌注，不构成内容。你这条到底赌什么？写不出来就是没赌注。

**5. 本条主验证目标**（只能选一项）：停留/看完、收藏、分享、评论、主页访问/关注、搜索/长尾、转化

**6. 辅助目标**（可空，只填一项）：______

**7. 增长四问**：
- 为什么停下来：______
- 当前价值：______
- 未来价值：______
- 主记忆资产：______

**8. 系列位置**（非系列留空）：系列名 / 第 N 集 / 下一集承诺 / 主页承接方式

> 填写指引：主验证目标决定脚本、CTA 和复盘盯什么，不是禁止其它行为自然发生。平台拿不到的数据留空并标“未知”，不得估算伪造。完整判断见 `references/10-增长与系列.md`。

## 二、我用什么打法

骨架决定完播。钩子只管前几秒，骨架管的是观众每一秒要不要划走。

**1. 骨架**：[钩子 → 痛点共鸣 → 反差观点 → 硬案例 → 收口，五段式是默认；若用别的推进动力请注明。]
> 接 03 §2.1 的六种推进动力，选哪种就写清让观众经历哪种心理过程：
> - 兴趣点推进（信息枚举 / 切片聚合，起号首选）
> - 戏剧性推进（悬念 + 障碍吊胃口）
> - 共鸣型推进（先小众后大众，顺序不能反）
> - 理性逻辑推进（二元对立站队 / 单方面碾压）
> - 节奏型推进（卡点 / 排比 / 押韵 / 长短句）
> - 卖点聚合（兴趣点的带货变体）
>
> 填写指引：别写「先讲背景再讲方法」这种散文式平铺。要写清每一段在干什么、承载什么情绪、往哪个终点推。

**2. 钩子手段**：[前两秒具体用什么。不是话术，是手段。]
> 接 03 §2.5 六种技巧：颠覆认知 / 找人背锅 / 制造对立 / 负面后果 / 美好愿景 / 句式升级。句式上否定句最强、肯定句次之、疑问句最弱——开篇别用「你们知道吗」。钩子挑情绪可以，具体声明（数字／疗效／收益／资质）必须真实。
>
> 填写指引：写「开头抛个问题吸引人」等于没写。要具体到前两秒那句话、那个画面、那个动作。信息差才是真钩子，话术是末节。

**3. 控制变量**（接 07 §一，硬纪律）：[这批只换 X，其余九成保持相同。]
> 填写指引：五到十条为一批，只换一个变量。这条改了开头就别同时换选题、换拍摄形式。两条就下结论是最常见的错误——一是样本太小有偶然性，二是变量没控住。写清楚：这一批里，这条相对上一条/下一批，**唯一**不同的是什么。

## 三、我预期什么（可验证预测）

这一段是你跟自己签的对赌单。发布前写死，发布后不许改。写不出可验证的预期，等于没想清楚就上场。

**1. 预期相对表现**（接 07 §二，以同平台、同形态、同支柱下近 30 天或最近 10-20 条可比内容的中位数为基线）：
- [ ] **低于基线**
- [ ] **接近基线**
- [ ] **高于基线**
- [ ] **显著高于基线，进入爆款承接观察**

**基线与为什么这么预期**：[写明基线口径和推理。不是「希望能火」，是「因为这条选题覆盖的人群是 X、信息差是 Y、可比内容中位数是 Z，所以我赌它高于/接近基线」。]
> 填写指引：绝对播放门槛只有在当期平台事实已核验时才可作为辅助依据，不能替代账号相对基线。

**2. 重点盯哪个指标**（必须与主验证目标一致，只选一项）：
- [ ] **前段留存 / 完播异常点**——主目标为停留/看完
- [ ] **收藏 / 分享 / 评论内容**——按对应主目标选择
- [ ] **主页访问与关注转化**——平台可得时
- [ ] **搜索来源与长尾增量**——主目标为搜索/长尾
- [ ] **系列相邻集表现**——系列内容
- [ ] **新粉留存**——平台可得时
- [ ] **私信 / 线索 / 成交**——主目标为转化，遵守高风险边界

**为什么盯这个**：[写清为什么是它，不是别的。]
> 填写指引：盯所有指标等于一个都没盯。挑一个最关键的，写清楚盯它的逻辑。

**3. 反事实**（如果不灵，最可能是哪个原因）：[写下来。]
> 填写指引：这一条最容易被跳过，但最有价值。提前想好「如果扑街，锅最可能在哪」，复盘时才不会乱归因。常见嫌疑：选题需求不痛、钩子没焊死需求与方案、骨架在第八秒势能泄漏、人设没同屏就突出、目标人群蹭错热点。

**4. 失败的可观测信号**（锅真出现时长什么样，不是"感觉不行"）：[写下这条扑街时你会看到的具体数字 / 曲线 / 评论现象。]
> 填写指引：反事实猜"锅在哪"，这一条写"锅真端上桌长什么样"。例：完播曲线第 8 秒断崖式下滑（骨架势能泄漏）；评论前 20 条全问价格 / 求链接而非讨论观点（人群蹭错）；点赞曲线只有开头铁粉峰、中段全零（需求没戳中）。写不出可观测信号=复盘时凭感觉乱归因。

## 四、回看约定

**1. 复盘时间**：发布后 T+[ ]（默认 T+3；不同平台数据稳定时间不同，按平台实情填）。把 N 写入头部 `review_after_days`；**待发布时不要预填 `next_review_date`**，发布后再用实际发布日期换算绝对日期。
> 填写指引：别一发布就盯数据，数据没稳定，归因全是错的。也别拖一周，情绪没了复盘就没劲。

**2. 需回收的数据清单**：
- [ ] 播放量、点赞、评论、分享、新增关注
- [ ] 完播曲线（重点截异常下滑点前后两三秒）
- [ ] 点赞曲线分布（开头铁粉 / 中段零碎 / 结尾集中）
- [ ] 评论前 20 条内容（看观众到底在讨论什么，是不是你赌的那个点）
- [ ] 新关注者头像抽样（看是什么人，对不对）
- [ ] 主页访问与关注转化（平台可得时）
- [ ] 搜索来源 / 长尾增量（适用时）
- [ ] 系列相邻集表现（适用时）
- [ ] 新粉 3/7/14 天留存（平台可得时）

**3. 验证窗口（样本量）**：本契约覆盖内容条数：[  ] 条（**3-5 条同向样本是「样本条数锚点」，可下轻结论但仍不重押；同一判断被不同内容 / 不同时间验证 ≥3 次，才是写进认知沉淀区下结论的统一门槛**）
> 填写指引：单条爆款 / 扑街都有偶然性。**先区分两个阈值**：「3-5 条同向样本」是样本条数锚点（可下轻结论，仍不重押）；「同一判断被不同内容 / 不同时间验证 ≥3 次」才是进认知沉淀区下结论的统一门槛。同方向（同骨架 / 同人群 / 同钩子）样本对齐，才在五 §2 下"这套打法成立/不成立"的结论。只 1 条就对账 ✅/❌，会把偶然当规律。
