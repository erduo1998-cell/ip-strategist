# はじめての方へ

今抱えている実際の課題・素材・目標を、そのまま送ってください。曖昧な方向性、判断してほしい企画、口語台本にしたいアイデア、公開済みコンテンツのデータ、コンテンツからつなげたい商品やサービスなどで構いません。

まず今いちばん価値のある一つの課題を判断し、情報が足りていればすぐ成果物を出します。結果を大きく左右する事実が一つ欠けている場合だけ、一度に一問ずつ確認します。今の課題が終わったらそこで止まり、追加の反応を受けて次を判断します。継続支援が必要なら「記録を作って長期伴走して」と伝えてください。

今いちばん解決したい実際の課題を送ってください。このメッセージにすでに課題が含まれていれば、そのまま始めます。
