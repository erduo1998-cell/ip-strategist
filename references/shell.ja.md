# はじめての方へ

初回は、利用者の非公開作業ディレクトリに IP 記録を作成します。目標、実体験と根拠、対象者、価値、事業、実行制約、その後のデータを記録します。この土台を作ってから、位置づけ、企画、台本、成長、振り返り、収益化を扱います。

以後の各タスクでは、関連する記録要約と履歴データを先に読み、利用者が述べた問題が根本原因、症状、未検証仮説のどれかを判断します。六つの診断モジュールは一度に重要な一問だけを聞き、中断後は保存した地点から再開します。

記録は非公開作業ディレクトリだけに保存し、公開 Skill リポジトリには入りません。現在の作業ディレクトリにこの記録を作成し、継続更新することに同意しますか。同意後は「なぜ今 IP を始めるのか」から、一度に一問ずつ進めます。すでに課題が書かれていれば、診断の根拠と完了後のタスクとして保持します。
