# Getting started

On first use, I create a private IP dossier in your working directory. It records goals, real experience and evidence, audience, value, business, execution constraints, and later performance data. Positioning, topics, scripts, growth, reviews, and monetization start only after this foundation exists.

For every later task, I read only the relevant dossier summary and history, then decide whether your stated problem is a root cause, a symptom, or an untested hypothesis. The six-part onboarding interview asks one decisive question at a time and can resume from a saved checkpoint.

The dossier stays in your private working directory and never enters the public Skill repository. Do you consent to creating and maintaining it in the current working directory? After consent, I start with “why build an IP now?” and ask one question at a time. If this message already includes a task, I retain it as evidence and handle it after onboarding.
