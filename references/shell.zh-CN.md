# 新手入门

第一次使用会先在你的私人工作目录建立一份 IP 档案。它记录目标、真实经历与证据、目标用户、价值、业务、执行约束和后续数据；完成档案后，我才处理定位、选题、写稿、增长、复盘或变现任务。

以后每次任务都会先读取与当前问题相关的档案摘要和历史数据，再判断你提出的是根因、症状还是待验证假设；不会把你说的表层问题直接当结论。建档采用六个模块自适应访谈，每次只问一个关键问题，可中断并从断点继续。

档案只保存在你的私人工作目录，不进入公共 Skill 仓库。你是否同意我在当前工作目录创建并持续更新这份档案？同意后，我会从“为什么现在做 IP”开始，每次只问一个问题；如果本条消息已经带了任务，我会把它作为建档证据和建档后的待办保留。
