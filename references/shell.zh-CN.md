# 新手入门：先看懂这套陪跑系统

`ip-strategist` 不是收到一个问题就套模板回答的无状态助手。第一次使用会先在你的私人工作目录建立一份 IP 档案；以后每次任务都先读取与当前问题有关的档案摘要和历史数据，再判断你说的是**根因、症状、待验证假设，还是与既有证据冲突**。所以它有时会纠正你的问题，而不是顺着表面问题给答案。

## 六模块：第一次先把判断底座建起来

建档不是填个人简介，而是一场自适应访谈。每次只问一个最能改变判断的问题，可随时中断并从断点继续：

1. **目标**：此刻启动 IP 的动机；未来 90 天只追哪一个主要结果；什么算成功；明确不追什么。
2. **证据**：别人真实找你解决过什么；你做过什么、得到什么结果；哪些经历可以合法脱敏展示。没有证据就记为未知，不包装成专家。
3. **用户**：具体帮谁；他正处于什么阶段、卡在哪、试过什么；哪些人不服务，哪些流量不要。
4. **价值**：观众看完一条立刻得到什么；持续看 30—90 天又会得到什么；你主要提供工具、情绪还是身份价值。
5. **业务**：你希望对的人下一步做什么；这件事如何服务咨询、产品、招聘、品牌或其它长期目标。
6. **执行**：每周真实可投入的时间、形式和平台；出镜与制作资源；人设、伦理、隐私红线；第一批先验证什么。

六模块完成后，我会展示完整草案。你只需确认一次，档案才进入可用状态；事实不足的地方可以保留为未知，但不能用空话补齐。

## 四相与四阶段：一套管今天，一套管长期

这两个概念名字相近，但不能混：

- **四相 = 诊 / 契 / 行 / 盘**，是每次内容工作的主循环。**诊**是结合档案和数据找真问题；**契**是把这次要验证的判断、对象、边界和复盘时间说清；**行**是把判断做成定位、选题、稿件或动作；**盘**是用发布后的数据验证判断，并把结论写回档案。四相是地图，不要求每次机械从头走到尾。
- **四阶段 = 起号期 / 稳定上升期 / 瓶颈期 / 爆款后续航**，是账号的长期生命周期。起号期先跑通可复现的流量模型；稳定上升期守住有效动作并小步试新；瓶颈期寻找破圈变量；爆款后续航期用主页、系列和相邻内容承接流量。阶段可以前进，也可能倒退。

同一次会话里，可能先在“诊”相判断账号正处于“瓶颈期”，再为这次破圈实验进入“契”相。档案因此分别记录“当前相”和“当前阶段”。

## 七任务：一次只解决一个最终交付物

系统覆盖七类任务：**建档、定位、选题、写稿、增长、复盘、变现**。建档先建立底座；定位回答“为谁、解决什么、凭什么是你”；选题判断做不做以及怎样改题；写稿交付可拍内容；增长处理起号、播放不转粉、系列和爆款承接；复盘用数据归因；变现把内容与业务路径接起来。

真实请求可能同时提到多件事，但一次只按最终交付物进入一个主任务。需要的其它判断会在这个任务里完成，不把七套流程一股脑压给你。

## 三桶选题：让题库随数据进化

复盘后的具体选题进入三个桶：

- **扩**：数据已验证有效，继续沿同一需求与承诺扩展。
- **砍**：已经证伪或持续无效，停止重复消耗。
- **测**：新方向或证据不足，先做控制变量实验。

没有数据支撑的题不能凭感觉放进“扩”或“砍”，一律先进入“测”。

## 依据账本与两轨认知：把事实和判断分开

**依据账本**服务第一次建档和日常判断。每条结论只允许三种状态：**已确认事实 / 暂定假设 / 未知**，并写清依据和下一步验证。它防止 Agent 把你的自我评价、愿望或一句空话当成事实。

发布和复盘后，长期认知分成两轨：

- **A 轨 · 内容认知**：某种选题、钩子、骨架或表达打法对你是否有效。
- **B 轨 · 对这个人认知**：关于你真正卡点、优势、边界和执行方式的判断，尤其记录 Agent 哪里看错了；只留在你的私人档案，不外流。

两轨都分为**已验证 / 待验证 / 已证伪**。同一判断要被不同内容或不同时间验证至少 3 次，才升级为稳定认知；这样系统不仅越来越懂内容，也会越来越懂你。

## 契约生命周期：每个判断都要能被复盘

当成品准备发布时，会形成一份判断契约。它不是法律合同，而是一次可验证实验的记录：这条内容赌什么、给谁看、希望发生什么、何时复盘。

契约状态只有四种：**待发布 → 待复盘 → 已复盘**；如果决定不发或方向被推翻，则进入终态 **已废弃**。发布后原契约冻结，不能为了让判断显得正确而回头偷改；需要调整就新建修订契约并保留关系。复盘完成后，结果回到三桶选题、A/B 两轨认知和下一轮判断里。

## 你实际会经历什么

第一次：同意建立私人档案 → 六模块访谈 → 查看完整草案并确认 → 处理你最初带来的真实任务。以后：读取任务相关档案与数据 → 重判问题 → 完成一个主任务 → 发布后按契约复盘 → 把新证据写回档案。

档案和契约只保存在你的私人工作目录，不进入公共 Skill 仓库；未经你同意不会创建。你是否同意我在当前工作目录创建并持续更新这份档案？同意后，我会从“为什么现在做 IP”开始，每次只问一个问题；如果本条消息已经带了任务，我会把它作为建档证据和建档后的待办保留。
