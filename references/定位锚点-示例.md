# 定位锚点 · 示例（虚构，仅供照抄格式）

> **⚠️ 脱敏示例，非总闸门；用户应自建人设锚点。** 本文件是**公开脱敏的格式样本**，不是任何真实创作者的定位锚点，**不能当作你自己档案里的总闸门直接套用**。它只演示「一句话定位／五要素／人设红线」这些字段怎么填、长什么样。真正能当总闸门用的锚点，必须由你在诊相里结合自己的人设、人群、赛道一步步建出来，写进你自己的 `ip-dossier.md` 底座区。照抄格式，不照抄内容；照抄了也守不住，因为你不是这个示例里的人。
>
> **这是什么：** 一份填好的「定位锚点」样本（**示例**），展示一个创作者的人设方向、红线、不变量怎么落到纸面上。**本文件里的一切人物、背景、数据都是虚构的，只为演示格式——照抄格式，不照抄内容。**
>
> **谁来填：** 由诊相（见 `08-陪跑闭环与档案.md` 的四相工作流）里创作者和 agent 共同确立，写进 `ip-dossier.md` 的「底座」区（见 `templates/dossier-template.md` 的「一句话定位／五要素／人设红线」字段）。每次选题铸造、写稿、复盘任务开始前，agent 先扫档案底座的这一区——它是这个创作者方向的总闸门。
>
> **与方法论的关系：** `references/00-11` 教"怎么做对"，定位锚点教"在为谁做、什么不能做"。方法论说怎么做对，锚点说怎么做才不跑偏。两者缺一不可。

## 一句话定位（示例）

**（示例）一个在幼儿园一线带过几百个"熊孩子"的二胎妈妈，把"怎么接住 3-6 岁孩子的情绪"这件事，讲到让第一次当爸妈的人秒懂、当晚就能上手。**

---

## 五要素锁定

### 价值

**工具价值**：3-6 岁孩子情绪爆发、社交冲突、入园焦虑时的具体应对话术和动作——"孩子在地上打滚要玩具，第一句话说什么、第二句说什么、什么时候该走开"。家长当晚就能试。

**情绪价值**：让第一次当爸妈、被孩子搞得崩溃又不好意思跟人说的家长，觉得"原来不是我一个人""有人看见我有多难"。

**身份价值**：让家长从"我是不是个不合格的爸妈"的自责里走出来，重新认定"我在学着做一个够好的爸妈"。

**不教**：早教理论名词、脑神经发育机理、育儿流派之争。这些东西家长听了用不上，不是这里的价值。判断标准是"家长今晚回去能不能直接用"，不是"听起来专不专业"。

> 价值三层的判断见 `01-定位与人设.md` 第二节：工具价值是底线（缺了难起号），情绪和身份价值是放大器（有了才涨粉、才长久）。

### 用户

3-6 岁孩子的家长，**第一次当爸妈，正在被孩子的情绪问题搞得崩溃**。

他们的状态：**爱孩子，但常常接不住。** 孩子一哭闹自己就先炸了，事后又自责；看过很多育儿号，道理都懂，一到现场全忘。不是"还没生"的人，是"生了、正在熬"的人。卡的不是知识点，是"那一刻我到底该说什么"。

### 人设（示例 · 在真实锚点里这才是"总闸门"）

> 下面这位「林姐」是**示例人设**，演示一条人设主线怎么写。在你的真实锚点里，人设这一条才是总闸门——写废了先回来查自己锚点的这一条，不是查这里。

**林姐是"踩过坑的过来人"，不是"高高在上的专家"。**

过来人的姿态：林姐带过几百个孩子、自己也炸过、也后悔过、慢慢摸出门道。她不说"你这样不对"，她说"我以前也这样，后来发现没用"。家长自己判断自己是不是在里面。

**共同问题**：那套"好爸妈就该情绪稳定、就该什么都接得住"的假标准。包括林姐在内的家长都承受着这套标准的压力。林姐和家长站在同一边，处理的是同一个不切实际的要求。

**差异化根源（六字真言之"正"，见 `01-定位与人设.md` 第四节）**：理论上不如儿童心理学家，但比他们更懂"家长在那一刻到底慌在哪"。心理学家讲依恋类型，林姐讲"孩子摔门那一刻你手该往哪放"。这个信息差，没在一线带过几百个孩子的人没有。

### 类型

讲述型 + 场景重现（口播为主，偶尔配简单的场景重现或道具演示）。不纯坐书房讲理论——那是被淘汰的形态。

### 风格

短句、温和但敢判断、说"家长听得懂的人话"、一线老师视角。不端专家架子，不堆育儿术语。

## 人设红线（示例 · 命中即打回，不可绕过）

> 这套红线是**示例**——它约束的是示例里的「林姐」，不是你。你档案里的人设红线，由你在建档时根据自己的定位当场定下。

### ❌ 绝对禁止

1. **教训家长的视角。** "你这样会毁了孩子""你根本不懂孩子"——全部禁止。过来人不教训，只讲自己当初怎么摔的。
2. **居高临下的专家定位。** 不许摆"我懂育儿你不懂，我来教你"的姿态。这个姿态一出现，不管选题多对，稿子永远是说教。
3. **贩卖焦虑当钩子。** "再不改就晚了""你家孩子已经出问题了"——用恐惧逼家长看下去，禁止。焦虑感的唯一合理用法是"戳中家长已经在焦虑的事"，不是制造新的焦虑。
4. **把家长当被教育对象。** 家长不是学生，是跟林姐一样被假标准困住的人。关系是"同一个战壕里的人"，不是"老师和学生"。
5. **纯理论型内容当唯一题型。** 连续讲"安全感""依恋""敏感期"这种概念堆砌，会让家长觉得"你又来讲课了"。必须混用场景还原、实操话术、真实案例。

### ✅ 必须做到

1. **过来人视角落地。** 讲一个坑的时候，林姐的位置是"我也踩过／我也炸过／我后来摸出来了"，不是"我在上面看着你们踩"。
2. **身教大于言传。** "我当时是这么处理的""我犯过的错"比"你应该怎样"更值得信任。展示怎么接住孩子，而不是告诉家长该怎么做。
3. **共同问题对准假标准，不对准家长。** 戳的是"那套不切实际的好爸妈标准"，不是戳家长。家长承受着标准带来的压力，不是不合格的人。
4. **今晚就能用。** 每条内容必须落到一个家长当晚就能试的话术或动作，不能停在"要给孩子安全感"这种正确的废话。

## 选题与写稿时的自检（每次动手前过一遍）

动笔前问自己五个问题，任何一个答"不"就停下来：

1. **这个选题是在戳假标准，还是在戳家长？** 戳家长 = 打回。
2. **林姐在这条稿子里，是过来人还是教训者？** 教训者 = 打回。
3. **这条稿子的核心动作，是家长今晚就能试的吗？** 停在理论 = 打回。
4. **家长听完开头第一句，能想到自家孩子昨晚的那个场景吗？** 想不到 = 换场景。
5. **这条是不是又在纯讲理论？** 如果是、且最近已经连续讲过 = 换题型。

## 与变现的关系（锚点不决定变现路径，但约束变现方式）

林姐的变现锚点：家长情绪应对的实操内容（工具价值）→ 信任建立（情绪／身份价值）→ 亲子沟通训练营 / 家长答疑社群 / 一对一咨询。

**红线约束变现**：不卖"不买就焦虑"的课程（违反红线 3）；不卖"专家诊断你家孩子问题"的高客单（违反红线 2）。变现方式必须和过来人姿态自洽——卖的是"我们一起练"，不是"我来救你"。

> 变现路径的完整判断见 `06-变现路径.md`，阶段节奏见 `09-阶段与节奏.md`。
