# 처음 사용하기

처음 사용할 때는 사용자의 비공개 작업 디렉터리에 IP 기록을 먼저 만듭니다. 목표, 실제 경험과 근거, 대상, 가치, 사업, 실행 제약, 이후 데이터를 기록합니다. 이 기반을 만든 뒤 포지셔닝, 주제, 대본, 성장, 회고, 수익화를 처리합니다.

이후 모든 작업에서는 현재 문제와 관련된 기록 요약과 과거 데이터를 먼저 읽고, 사용자가 말한 문제가 근본 원인인지 증상인지 검증되지 않은 가설인지 판단합니다. 여섯 진단 모듈은 한 번에 핵심 질문 하나만 하며 저장된 지점에서 이어갈 수 있습니다.

기록은 비공개 작업 디렉터리에만 저장되고 공개 Skill 저장소에는 들어가지 않습니다. 현재 작업 디렉터리에 이 기록을 만들고 계속 갱신하는 데 동의하시나요? 동의하면 “왜 지금 IP를 만들려는가”부터 한 번에 한 질문씩 진행합니다. 이미 작업이 포함되어 있다면 진단 근거와 온보딩 이후의 할 일로 보존합니다.
