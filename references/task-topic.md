# 找题、判题与改题

## 本任务解决什么

把方向、观点、知识点或热点变成目标用户愿意看的可执行选题；也判断一个现成题目值不值得做。交付的是取舍与可拍题目，不是泛泛灵感清单。

## 最少输入

- 必需：目标人群或可合理推断的人群；待判断的题目/方向，或创作者可提供的真实经验与方案。
- 可假设：平台、时长、形式不影响题目内核时，采用用户常用平台与短视频默认场景并标注。
- 必须追问：不知道给谁看，或创作者没有可真实讲述的证据/方案，且不同答案会改变题目取舍。一次只问一个最高价值问题。

平台热度、算法权重与实时趋势不可凭记忆断言。用户要求“现在最热”或策略依赖热点时，先核验一手来源；核验不了就把它标为待验证假设。

## 决策路径

### 1. 先过选题三问

把候选题拆成“需求 × 解决方案”：

1. **具体需求**：哪类人在什么处境下，正为什么问题付出注意力？“如何变美”“女性成长”不是具体需求。
2. **站得住的方案**：创作者要给什么方法、视角、信息差、过程或体验？只有疼点没有方案只是话题。
3. **去掉需求仍有信息吗**：去掉需求半句后，若没有独立成立的方案、视角或反转，就打回重铸。

事实、案例、资质和结果必须真实。需求可以来自评论、搜索、真实咨询、自身经历和未发声人群，但不能凭宏大词想象“所有人”。热点必须与目标人群匹配，吸错人比没有流量更危险。

### 2. 判断这条赌什么

只选一个主赌注，不能五种都沾：

- 资讯：赌真实信息差。
- 观点：赌有理据的认知缺口或反常识，不靠硬造对立。
- 步骤技巧：赌低行动成本、可操作且有新鲜度。
- 生活/故事：赌令人向往、共鸣或有指导意义；普通流水账不成立。
- 新体验：赌真实状态、投入或表达方式本身能带来感受。

若创作者的核心只是一个论点，先向下追一层底层判断，再给它外壳：真实处境 + 信息差/反转/情绪张力。外壳服务内核，不做标题党。陌生方案应在开头把需求和方案焊在一起，不能先解释半天概念。

### 3. 生成与筛选

找题时可从两个方向并行：

- 从需求找方案：真实问题 → 五种方案类型。
- 从创作者的方案/经历反推需求：独有经验 → 谁在什么时刻最需要它。

需要一组题时先超量生成，再筛选；优先保留人群明确、需求有证据、方案可信、主赌注清楚、与定位/业务相容的题。成本、人群、反差、怀旧等传播元素只能放大真实内核，不能编数字、消费创伤、制造身份攻击或焦虑。

改题时指出原题坏在哪一半，再给可执行改法，不只换标题。若要求做系列，至少提取“稳定承诺 + 可变变量 + 单集独立价值”，不要只在相似标题前加编号。

### 4. 给结论

- **做**：需求与方案都成立，赌注清楚，创作者能真实兑现。
- **改后做**：需求成立但方案普通/外壳弱，或方案好但人群处境不清。
- **暂不做**：缺真实证据、吸引错误人群、依赖未经核验的平台传言，或以操控和造假为动力。

## 交付物契约

判题默认输出：

1. 一句话结论：做 / 改后做 / 暂不做。
2. 目标人群与具体处境。
3. 需求半句、方案半句、主赌注。
4. 最终可拍选题表达（必要时给 2—3 个强度不同版本）。
5. 最大风险与最小验证方式。

找题默认给一小组经过筛选的题，每题写清“给谁、赌什么、为什么由你讲”，最后明确优先级。不要输出几十个同义标题、空洞爆款分数、完整脚本或方法论讲义。

## 失败与升级条件

- 用户只给空赛道且没有人群/证据：问一个能找到真实人物或真实经历的问题。
- 涉及医疗、法律、金融、安全等高影响内容：不得把专业判断包装成流量选题；要求可靠来源与资质边界。
- 用户要求复制某创作者：提取需求和结构机制，拒绝复制其独特文案、人设、案例或受保护表达。
- 常规三问仍出现真实冲突，或用户要深讲依据：才局部查询深层方法论。

## 交付前自检

- 这是完整选题，不是只有名词的话题吗？
- 人群、处境、方案和主赌注是否都能指认？
- 创作者凭什么讲，是否真实？
- 外壳是否服务内核而非制造恐惧、羞耻或群体对立？
- 是否没有把未经核验的热点/算法传言当事实？
