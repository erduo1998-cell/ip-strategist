# 脚本骨架、口播成稿与表现意图

## 本任务解决什么

把用户的方向、观点、素材或选题直接做成可拍的短视频脚本/口播逐字稿，并在确有必要时给最少镜头与表演意图。即使请求包含“先选题再写稿”，也在本胶囊内完成最小判题，不另读选题胶囊。

## 最少输入

- 前置：已通过档案门并取得 script 摘要；缺档案或建档为 `in_progress` 时不得执行本胶囊，必须先完成 onboarding。
- 必需：想表达的核心材料/方向；目标人群或可从上下文推断的人群；期望的成品形态（骨架/逐字稿）与大致时长。
- 可假设：平台、口吻、场景未指定时，采用用户语言下自然的短视频口播，并在稿前用一句说明关键假设。
- 必须追问：档案摘要仍无法回答给谁看、希望发生什么、或创作者凭什么讲，且不同答案会改变主张或事实边界。一次只问一个。无档案的有限降级只能交明确标注低置信度的临时稿，不得冒充基于用户底座的精准成稿。

## 决策路径

### 0. 先判断该不该写这条

对照档案中的定位、目标用户、90 天目标、当前主行为、人设红线、历史数据和已证伪认知。用户说“帮我写稿”不代表写稿是真问题；若选题吸错人、主张与证据冲突、当前更应补产品或主页承接，先纠偏，不用文案质量掩盖战略错误。

### 1. 再做最小判题

在动笔前补齐：

- **具体需求**：谁在什么处境下为什么愿意看。
- **解决方案/主张**：这条给什么方法、视角、信息差、过程或感受。
- **主赌注**：资讯、观点、步骤、故事/生活或新体验，只选主要动力。
- **主行动**：看完/收藏/分享/评论/关注/转化中的一个主验证目标。

若只有论点，向下追到一个更有重量的底层判断，再给真实处境与信息差外壳。若需求或方案根本不成立，先改题再写；不要用好文案掩盖空选题。

### 2. 选择一条推进动力

不要堆模板，按材料选主结构：

- **解题/知识**：具体场景难题 → 低成本方案 → 操作步骤；先易后难，重操作和获得感。
- **观点**：明确站在目标用户一侧；观点 + 2—3 个有效论据，或正反案例对照。可以有力，事实不可造假或选择性误导。
- **共鸣**：先用小众、具体、陌生细节吸引，再走向共同经历；具象为主，抽象句只作路标。
- **故事/过程**：人物欲望 → 打破平衡的事件 → 逐步升级的真实障碍 → 服务价值观的结果。只保留与核心对抗有关的情节。
- **节奏/聚合**：围绕同一主题并列 n 个有独立价值的点，最后聚合释放；适合卖点、清单和情绪排比。

全稿只去一个终点。持续管理注意力：承诺与交付一致；删旁枝和过度解释；用转折、具体事件和信息块推进。留白不是隐瞒关键事实，不把话说满也不能误导。

### 3. 写成人话

- 先把“对谁说、为什么现在说、想让对方怎样”钉死，再写台词。
- 一句只承载一个意义单元；短句为主，长短交替，念出声能一口气完成。
- 用具体人物、动作、场景和物件替代抽象形容；像谈话，不像论文、课程提纲或 AI 总结。
- 开头 2—5 秒直接给人群、处境、冲突、结果承诺或信息差，避免“大家好/你知道吗/今天聊聊”。钩子只能放大真实问题，不编危机、数据、疗效、收益和资质。
- 结尾完成主目标：给可执行动作、可回答问题、具体未来价值或业务下一步，不用空泛“关注我下期更精彩”。
- 跟随创作者已有语气；没有样本时用自然、直接、不端着的口语，不臆造方言、口头禅或身份。

### 4. 只给必要的表现与镜头意图

镜头建议服务脚本，不替代拍摄/剪辑：

- 给一个规定情境、说话对象和行动动机，避免“表现得自然/更有情绪”这种不可执行指令。
- 可用动作中说话、关键句动作停顿、重音/轻读信息块，让身体与气息承载意义。
- 场景与景别先服务人设和信息：特写强调情绪/质地，中景讲事，全景交代空间；不为炫技堆调度。
- 若用户只要纯文案，不强塞分镜；若镜头无法由现有事实决定，给意图而不是假定具体场地和设备。

## 交付物契约

用户要逐字稿时默认输出：

1. 一句创作判断（人群、主张、主赌注、主行动）。
2. 可直接念的完整稿；按时长控制篇幅，必要时标停顿/重音但不满篇符号。
3. 仅当能显著改善成品时，补 3—6 条表现/镜头意图。
4. 一条最大风险或发布后应验证的信号。

成品准备发布时，按统一入口的状态纪律进入契相：完整展示一份判断契约，用户一次无歧义确认后写入 `待发布` 原件；不代签。有限降级不签契约。

用户只要骨架时，输出开头承诺、推进段、关键转折/刺点、结尾行动和各段目的，不擅自写成长篇成稿。不要输出完整方法论、套路目录、读取回执或剪辑后期指令。

## 失败与升级条件

- 材料含不可核验的具体事实：标记待核实或删除，不替用户补造。
- 底层动力是恐惧、羞耻、身份攻击或对弱势群体操控：打回重做动力。
- 医疗、金融、法律、安全等高影响主题：只保留可靠来源支持的内容，明确资质与非专业建议边界。
- 创作者要求照抄某作者：可提炼机制，不复制独特文案、结构表达或案例。
- 结构选择出现真实冲突、用户要求深入依据时，才局部查深层章节。

## 交付前自检

- 需求、方案、主赌注是否都成立？
- 开头承诺与后文交付一致吗？
- 是否只有一条主线和一个主行动，旁枝已删除？
- 每个抽象判断是否至少有具体事件、动作或例证承接？
- 念出声是否自然；是否存在长书面句、AI 套话或空泛口号？
- 事实、案例、资质、数据是否真实且未误导？
- 表现意图是否可执行且未越界到剪辑后期？
