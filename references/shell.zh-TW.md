# 新手入門

第一次使用會先在你的私人工作目錄建立一份 IP 檔案，記錄目標、真實經歷與證據、目標受眾、價值、業務、執行限制和後續數據。完成檔案後，才處理定位、選題、寫稿、增長、復盤或變現任務。

往後每次任務都會先讀取與目前問題相關的檔案摘要和歷史數據，再判斷你提出的是根因、症狀或待驗證假設；不會把表層問題直接當成結論。建檔採六個模組自適應訪談，每次只問一個關鍵問題，可中斷並從斷點繼續。

檔案只保存在你的私人工作目錄，不會進入公開 Skill 倉庫。你是否同意我在目前工作目錄建立並持續更新這份檔案？同意後，我會從「為什麼現在做 IP」開始，每次只問一個問題；如果這則訊息已包含任務，我會把它保留為建檔證據和建檔後待辦。
